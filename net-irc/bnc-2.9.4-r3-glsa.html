▸ GLSA 200411-24 BNC: Buffer overflow vulnerability this version unaffected high remote 2004-11-16

BNC contains a buffer overflow vulnerability that may lead to Denial of Service and execution of arbitrary code.

Announced
2004-11-16
Revised
2004-11-16
Access
remote
Bugs
#70674
Advisory
https://security.gentoo.org/glsa/200411-24

Affected packages

PackageArchVulnerableUnaffected
net-irc/bnc*< 2.9.1>= 2.9.1

Background

BNC (BouNCe) is an IRC proxy server.

Description

Leon Juranic discovered that BNC fails to do proper bounds checking when checking server response.

Impact

An attacker could exploit this to cause a Denial of Service and potentially execute arbitary code with the permissions of the user running BNC.

Workaround

There is no known workaround at this time.

Resolution

All BNC users should upgrade to the latest version:

# emerge --sync
# emerge --ask --oneshot --verbose ">=net-irc/bnc-2.9.1"

▸ GLSA 200410-13 BNC: Input validation flaw this version unaffected normal remote 2004-10-15

BNC contains an input validation flaw which might allow a remote attacker to issue arbitrary IRC related commands.

Announced
2004-10-15
Revised
2006-05-22 (revision 2)
Access
remote
Bugs
#66912
Advisory
https://security.gentoo.org/glsa/200410-13

Affected packages

PackageArchVulnerableUnaffected
net-irc/bnc*< 2.8.9>= 2.8.9

Background

BNC is an IRC proxying server

Description

A flaw exists in the input parsing of BNC where part of the sbuf_getmsg() function handles the backspace character incorrectly.

Impact

A remote user could issue commands using fake authentication credentials and possibly gain access to scripts running on the client side.

Workaround

There is no known workaround at this time.

Resolution

All BNC users should upgrade to the latest version:

# emerge sync

# emerge -pv ">=net-irc/bnc-2.8.9"
# emerge ">=net-irc/bnc-2.8.9"
