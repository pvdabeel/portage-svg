Background

Xerces-C++ is a validating XML parser written in a portable subset of C++.

Description

Multiple vulnerabilities have been discovered in Xerces-C++. Please review the CVE identifiers referenced below for details.

Impact

A remote attacker could entice a user to process a specially crafted file, possibly resulting in the remote execution of arbitrary code with the privileges of the process, or a Denial of Service condition.

Workaround

There is no known workaround at this time.

Resolution

All Xerces-C++ users should upgrade to the latest version:

# emerge --sync
# emerge --ask --oneshot --verbose ">=dev-libs/xerces-c-3.1.4-r1"

▸ GLSA 200903-19 Xerces-C++: Denial of service this version unaffected normal remote 2009-03-09

An error in Xerces-C++ allows for a Denial of Service via malicious XML schema files.

Announced
2009-03-09
Revised
2009-03-09
Access
remote
Bugs
#240496
Advisory
https://security.gentoo.org/glsa/200903-19

Affected packages

PackageArchVulnerableUnaffected
dev-libs/xerces-c*< 3.0.0-r1>= 3.0.0-r1

Background

Xerces-C++ is a validating XML parser written in a portable subset of C++.

Description

Frank Rast reported that the XML parser in Xerces-C++ does not correctly handle an XML schema definition with a large maxOccurs value, which triggers excessive memory consumption during the validation of an XML file.

Impact

A remote attacker could entice a user or automated system to validate an XML file using a specially crafted XML schema file, leading to a Denial of Service (stack consumption and crash).

Workaround

There is no known workaround at this time.

Resolution

All Xerces-C++ users should upgrade to the latest version:

# emerge --sync
# emerge --ask --oneshot --verbose ">=dev-libs/xerces-c-3.0.0-r1"
