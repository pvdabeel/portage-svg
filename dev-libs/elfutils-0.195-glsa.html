▸ GLSA 201710-10 elfutils: Multiple vulnerabilities this version unaffected normal remote 2017-10-13

Multiple vulnerabilities have been found in elfutils, the worst of which may allow remote attackers to cause a Denial of Service condition.

Announced
2017-10-13
Revised
2017-10-13
Access
remote
Bugs

Affected packages

PackageArchVulnerableUnaffected
dev-libs/elfutils*< 0.169-r1>= 0.169-r1

Background

Elfutils provides a library and utilities to access, modify and analyse ELF objects.

Description

Multiple vulnerabilities have been discovered in elfutils. Please review the referenced CVE identifiers for details.

Impact

A remote attacker could possibly cause a Denial of Service condition via specially crafted ELF files.

Workaround

There is no known workaround at this time.

Resolution

All elfutils users should upgrade to the latest version:

# emerge --sync
# emerge --ask --oneshot --verbose ">=dev-libs/elfutils-0.169-r1"

Packages which depend on this library may need to be recompiled. Tools such as revdep-rebuild may assist in identifying some of these packages.

▸ GLSA 201612-32 elfutils: Heap-based buffer overflow this version unaffected normal remote 2016-12-13

A heap-based buffer overflow vulnerability in elfutils might allow remote attackers to execute arbitrary code.

Announced
2016-12-13
Revised
2016-12-13 (revision 2)
Access
remote
Bugs
#507246
Advisory
https://security.gentoo.org/glsa/201612-32

Affected packages

PackageArchVulnerableUnaffected
dev-libs/elfutils*< 0.159>= 0.159

Background

Elfutils provides a library and utilities to access, modify and analyse ELF objects.

Description

An integer overflow, in the check_section function of dwarf_begin_elf.c, in the libdw library can lead to a heap-based buffer overflow.

Impact

A remote attacker could entice a user to open a specially crafted file, possibly resulting in the execution of arbitrary code with the privileges of the process or a Denial of Service condition.

Workaround

There is no known workaround at this time.

Resolution

All elfutils users should upgrade to the latest version:

# emerge --sync
# emerge --ask --oneshot --verbose ">=dev-libs/elfutils-0.159"

▸ GLSA 200506-01 Binutils, elfutils: Buffer overflow this version unaffected normal remote 2005-06-01

Various utilities from the GNU Binutils and elfutils packages are vulnerable to a heap based buffer overflow, potentially resulting in the execution of arbitrary code.

Announced
2005-06-01
Revised
2006-05-22 (revision 2)
Access
remote
Bugs
#91398 #91817
Advisory
https://security.gentoo.org/glsa/200506-01

Affected packages

PackageArchVulnerableUnaffected
dev-libs/elfutils*< 0.108>= 0.108
sys-devel/binutils*< 2.16-r1>= 2.14.90.0.8-r3 (revision), >= 2.15.90.0.1.1-r5 (revision), >= 2.15.90.0.3-r5 (revision), >= 2.15.91.0.2-r2 (revision), >= 2.15.92.0.2-r10 (revision), >= 2.16-r1

Background

The GNU Binutils are a collection of tools to create, modify and analyse binary files. Many of the files use BFD, the Binary File Descriptor library, to do low-level manipulation. Elfutils provides a library and utilities to access, modify and analyse ELF objects.

Description

Tavis Ormandy and Ned Ludd of the Gentoo Linux Security Audit Team discovered an integer overflow in the BFD library and elfutils, resulting in a heap based buffer overflow.

Impact

Successful exploitation would require a user to access a specially crafted binary file, resulting in the execution of arbitrary code.

Workaround

There is no known workaround at this time.

Resolution

All GNU Binutils users should upgrade to the latest version:

# emerge --sync
# emerge --ask --oneshot --verbose sys-devel/binutils

All elfutils users should upgrade to the latest version:

# emerge --sync
# emerge --ask --oneshot --verbose ">=dev-libs/elfutils-0.108"
