▸ GLSA 202210-38 Expat: Denial of Service this version unaffected low remote 2022-10-31

A vulnerability has been found in Expat which could result in denial of service.

Announced
2022-10-31
Revised
2022-10-31
Access
remote
Bugs
#878271
Advisory
https://security.gentoo.org/glsa/202210-38

Affected packages

PackageArchVulnerableUnaffected
dev-libs/expat*< 2.5.0>= 2.5.0

Background

Expat is a set of XML parsing libraries.

Description

In certain out-of-memory situations, Expat may free memory before it should, leading to a use-after-free.

Impact

A use-after-free can result in denial of service.

Workaround

There is no known workaround at this time.

Resolution

All Expat users should upgrade to the latest version:

# emerge --sync
# emerge --ask --oneshot --verbose ">=dev-libs/expat-2.5.0"

# emerge --sync
# emerge --ask --oneshot --verbose ">=dev-libs/expat-2.1.0_beta3"

Packages which depend on this library may need to be recompiled. Tools such as revdep-rebuild may assist in identifying some of these packages.
