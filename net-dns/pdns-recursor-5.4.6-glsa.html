▸ GLSA 202012-19 PowerDNS Recursor: Denial of service this version unaffected low remote 2020-12-23

A vulnerability in PowerDNS Recursor could lead to a Denial of Service condition.

Announced
2020-12-23
Revised
2020-12-23
Access
remote
Bugs
#746923
Advisory
https://security.gentoo.org/glsa/202012-19

Affected packages

PackageArchVulnerableUnaffected
net-dns/pdns-recursor*< 4.3.5>= 4.3.5

Background

PowerDNS Recursor is a high-end, high-performance resolving name server.

Description

It was discovered that it was possible to update the DNSSEC validation state to a bogus state for a cached record via DNS ANY query.

Impact

A remote attacker could send specially crafted DNS queries to deny DNSSEC validation.

Workaround

There is no known workaround at this time.

Resolution

All PowerDNS Recursor users should upgrade to the latest version:

# emerge --sync
# emerge --ask --oneshot --verbose ">=net-dns/pdns-recursor-4.3.5"

References

  • CVE-2020-25829
  • PowerDNS Security Advisory 2020-07

▸ GLSA 200804-22 PowerDNS Recursor: DNS Cache Poisoning this version unaffected normal remote 2008-04-18

Use of insufficient randomness in PowerDNS Recursor might lead to DNS cache poisoning.

Announced
2008-04-18
Revised
2008-08-21 (revision 3)
Access
remote
Bugs
#215567 #231335
Advisory
https://security.gentoo.org/glsa/200804-22

Affected packages

PackageArchVulnerableUnaffected
net-dns/pdns-recursor*< 3.1.6>= 3.1.6

Background

The PowerDNS Recursor is an advanced recursing nameserver.

Description

Amit Klein of Trusteer reported that insufficient randomness is used to calculate the TRXID values and the UDP source port numbers (CVE-2008-1637). Thomas Biege of SUSE pointed out that a prior fix to resolve this issue was incomplete, as it did not always enable the stronger random number generator for source port selection (CVE-2008-3217).

Impact

A remote attacker could send malicious answers to insert arbitrary DNS data into the cache. These attacks would in turn help an attacker to perform man-in-the-middle and site impersonation attacks.

Workaround

There is no known workaround at this time.

Resolution

All PowerDNS Recursor users should upgrade to the latest version:

# emerge --sync
# emerge --ask --oneshot --verbose ">=net-dns/pdns-recursor-3.1.6"

References

  • CVE-2008-1637
  • CVE-2008-3217
