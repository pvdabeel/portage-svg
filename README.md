# Portage-ng Interactive Package Graphs

Interactive HTML visualisations of Gentoo Portage ebuilds, generated by
[portage-ng](https://github.com/pvdabeel/portage-ng) `--graph`.

## Per-package pages

Each ebuild version has the following interactive HTML pages:

| Page | Description |
|------|-------------|
| **detail** | Hybrid tree/outline view with candidate versions and SVG graph toggle |
| **deptree** | Layered dependency graph with pan/zoom, collapsible nodes, and dep-type tabs |
| **gantt** | Step-based execution plan timeline with per-package USE flags and download details |
| **merge** | Terminal output of the portage-ng merge plan |
| **fetchonly** | Terminal output of the fetch-only plan |
| **info** | Terminal output of package info |
| **emerge** | Terminal output of traditional Gentoo emerge for comparison |

## Browsing

Open `index.html` in the root to browse by category and package.
All pages share a navigation bar for switching between graph types and
package versions, and support day/night theme switching.
